# Edge Auto Scroller Extension

A Microsoft Edge extension that automatically scrolls webpages, novels, and short‑form video feeds. Designed for hands‑free reading, continuous chapter navigation, and automated short‑video browsing.

## Intended Features

### 🌐 General Webpage Mode

- Smooth auto‑scrolling for any webpage
- Speed presets and custom speed slider

### 📖 Novel Mode

- Auto‑scrolls long text pages at adjustable speeds
- Detects and auto‑clicks “Next Chapter”
- Optional AI text‑to‑speech reader for hands‑free reading

### 🎬 Short Video Mode

- Auto‑scrolls short video feeds
- Waits for each video to finish before scrolling to the next one
